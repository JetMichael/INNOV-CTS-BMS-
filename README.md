## CTS BMS / CTS BMS 配置工具

### App Description / 应用描述
CTS BMS is a Bluetooth (BLE) tool for configuring and monitoring CTS battery management system (BMS) devices. Connect over BLE, send the device MAC address, read live battery and cell data, rename the device, record CAN bus logs, and export logs to share with others.
CTS BMS 是一款通过蓝牙（BLE）配置与监控 CTS 电池管理系统（BMS）设备的工具。通过蓝牙连接，下发设备 MAC 地址，读取实时电池与电芯数据，重命名设备，录制 CAN 总线日志，并导出日志与他人分享。

### Main Features / 主要功能
- BLE device connection: scan, connect and configure CTS BMS devices / 蓝牙设备连接：扫描、连接并配置 CTS BMS 设备
- Live telemetry: read battery voltage, current, temperature and cell data over Bluetooth / 实时遥测：通过蓝牙读取电池电压、电流、温度与电芯数据
- Device rename / 设备重命名
- CAN bus recording: save CAN logs as local files / CAN 总线录制：将 CAN 日志保存为本地文件
- Log export & share: export CAN logs via system share or email / 日志导出与分享：通过系统分享或邮件导出 CAN 日志
- Local MAC history / 本地 MAC 历史记录
- Chinese and English interface / 中英文界面

### Technical Info / 技术信息
- Framework: Flutter / 开发框架：Flutter
- Bluetooth: FlutterBluePlus / 蓝牙库：FlutterBluePlus
- Local storage: path_provider & shared_preferences (no cloud, no account) / 本地存储：path_provider 与 shared_preferences（无云端、无账号）
- Supported OS: iOS 16.0+ / Android / 支持系统：iOS 16.0+ / Android
